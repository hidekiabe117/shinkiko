# 真氣光（SHINKIKO）

株式会社エス・エー・エス（SAS Inc.）が運営する、氣のリラクゼーション。公式サイト https://shinkiko.com/

## 構成
- `brief.md` … 目的・対象・トーン（最初に読む）
- `brand/` … 色・ロゴ・フォント・文体
- `scripts/` … ショート動画の脚本（日付ごと）
- `assets/` … 素材（`raw/` 生素材、`ref/` 参考）
- `output/` … 完成物
- `ops/` … 手順書、費用の記録、定期実行の設計
- `CLAUDE.md` … Claude への作業ルール

## 注意
- 動画の実ファイル（mp4 等）は Git に入れない（`.gitignore` 済み）。置き場所は `assets/README.md` に記録する。
